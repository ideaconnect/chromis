# Chromis 1.4.1 (build 9)

Previous release: 1.4.0+8. A **patch** bump: one change to which of the
phone's own fonts are offered, nothing new to use. Bumped in `pubspec.yaml`
and `AboutInfo.appVersion`; build on Flutter 3.44.9, as for 1.4.0.

**Upload 1.4.1 in place of 1.4.0.** 1.4.0 was tagged but this supersedes it,
so Play users go from 1.3.1 straight to 1.4.1 and its "What's new" is 1.4.0's
verbatim (`whatsnew-1.4.1.txt`). If 1.4.0 did reach a track first, replace
that text with a single line - nothing in this release is visible enough to
announce.

## What is in it

**The font picker offers a phone font only if the font's own file declares
the SIL Open Font License or the Apache License 2.0** (name ids 13 and 14).
1.4.0 offered every Latin family Android names in `fonts.xml`, which on a
Pixel or a Samsung phone includes the maker's own faces - Google Sans, the
One UI fonts - licensed for the maker's software rather than for pictures
made in another app. The app never copied or redistributed those files, but
offering them was a licensing question the app's own policy (OFL / Apache /
MIT / BSD only) answers no to. A font that does not state its licence is not
offered at all.

Nothing changes on stock Android: all nine of the emulator's families are OFL
or Apache and all nine are still offered. A project that already used a maker
font keeps its family name and draws in the fallback face.

## The licence audit behind it

Done after 1.4.0 was tagged, on the shipped files:

- All 18 bundled families declare OFL 1.1 or Apache 2.0 in their own name
  tables, with `fsType` 0 (no embedding restrictions).
- All are byte-identical to google/fonts, so nothing is a Modified Version and
  the Reserved Font Names (Lobster, Press Start 2P, Titan) are not in play.
- Every family's licence text is a bundled asset, registered for the in-app
  licence page and listed in the About notices. Neither Apache font has a
  NOTICE file upstream.
- The website's subset Manrope and Space Grotesk are modified copies, which
  the OFL allows under the original name because neither reserves one; the
  page links both licences.
- `bundled_licenses_test` now fails the build for a bundled font with no
  licence registered - it claimed to check fonts and only checked models.

## How it was verified

`flutter analyze` clean, `flutter test` green. On the API 37 emulator:
`device_fonts_device_test` (every offered family's file states an open
licence; 9 families), the text and bubble BDD features, and the signed
release bundle builds.
