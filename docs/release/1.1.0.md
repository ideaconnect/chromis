# Chromis 1.1.0 (build 3)

Previous release: 1.0.1+2. A **minor** bump, not a patch: this release adds
a feature (comic bubble formats), so semver says 1.1.0. Bumped in `pubspec.yaml` - Play rejects an upload
that reuses a versionCode, so the `+3` is not optional.

## Play Console "What's new"

Paste `whatsnew-1.1.0.txt` verbatim. **489 characters** (494 counting CRLF line
endings), against Play's 500-character cap - so it survives a paste that
converts line endings, with ~6 characters to spare. English (en-GB / en-US) is
the only listed language.

## What is in it

A feature, and a set of fixes for things that were broken for real users.

**New - comic bubble formats.** Adding a bubble opens a picker showing all five
formats drawn by the real painter (Speech, Thought, Shout, Caption, Whisper).
Before, tapping "Bubble" silently dropped a plain speech bubble and the other
four lived in a panel most people never opened. Adding one now also confirms
itself: a toast naming the format, a panel headed "Comic bubble", and the format
row scrolled to the one just chosen.

**Fixed - would lose work or money**

- Duplicating a project and editing either copy could permanently delete the
  other copy's AI cut-out.
- Saving to the gallery failed on *every* Android 8 and 9 device, and each retry
  spent another rewarded ad.
- A failed export could consume a rewarded ad before producing anything.
- Pro was not restored automatically on reinstall or a new device.
- Purchase failures (already owned, billing unavailable, declined) did nothing
  visible.
- Autosave failures were silent and dropped the pending snapshot.
- A finished AI cut-out was discarded if the sheet was closed while it ran.
- Deleting projects had stopped reclaiming storage once any manifest was
  quarantined.

**Improved** - pinch-zoom no longer blinks the photo; screen-reader labels and
larger tap targets on the icon buttons, colour swatches and the delete handle;
toasts stay readable, are announced, and show red on failure; EEA/UK users can
change ad consent any time from Privacy & Cookies.

## Build

```bash
flutter build appbundle --release   # -> build/app/outputs/bundle/release/app-release.aab
flutter build apk --release         # sideload / manual check
```

`android/key.properties` and `secrets/chromis-upload.jks` must be present, or
the signing config silently falls back to **debug keys** and Play refuses the
upload. Confirm the AAB is signed with the upload key before uploading.

## Still open

- Storage: 35 MB of the install is the bundled MobileSAM + U²-Netp models.
  Re-exporting the MobileSAM decoder as fp16 (its encoder already is) would save
  roughly 7 MB; needs the `model_conversion` toolchain and a re-validated export.
- `minSdk` stays at **26**. The pre-Android-10 gallery path was fixed rather than
  dropped; raising it to 29 would delete that code but also those devices.
- `editor_screen.dart` is still 4,666 lines. Splitting it is the right move and
  the wrong week.
