# Chromis 1.3.1 (build 7)

Previous release: 1.3.0+6. A **patch** bump: four fixes for what Play Console
reported against 1.3.0, and nothing new to use, so semver says 1.3.1. Bumped in
`pubspec.yaml` and `AboutInfo.appVersion` - Play rejects an upload that reuses a
versionCode, so the `+7` is not optional.

**Build it on Flutter 3.44.9**, the version CI pins (#65). 3.44.6 leaks
`sync_file` descriptors on every banner refresh, and 3.47 deadlocks the Mali
driver on MediaTek phones below vendor SDK 32.

## Play Console "What's new"

Paste `whatsnew-1.3.1.txt` verbatim. Longest is fr-FR at 493 of 500, counting
the newlines twice; `python tool/check_store_listings.py` measures it.

## What is in it

One fix per Play report. None of the four could be reproduced on a device we
own, so each was verified on the API 37 emulator as far as an emulator can go,
and the real check is the cluster going quiet in Android vitals.

**The app no longer closes on Snapdragon 8 Gen 5 / 8 Elite Gen 5 (#64).**
Galaxy S26, razr fold, OnePlus 15: SIGILL in `OrtSession.run` the moment Remove
object was opened. ORT 1.23 enabled its KleidiAI kernels on any CPU reporting
SME, and they are SME2 code. Two independent fixes: `flutter_onnxruntime`
1.8.2 → 1.9.0 (ORT 1.28, which picks SME or SME2 at runtime), and every session
sets `mlas.disable_kleidiai=1`. The emulator never runs the arm64 path that
crashed.

**Back on Home no longer tears the engine down (#65).** Mali `SIGABRT` in
`libGLES_mali.so`: Flutter answers the last back with `finish()`, and Impeller
frees fences the driver is still signalling while the banner's WebView draws
into its texture. Back now moves the task to the background, as Android 12+
does for other apps. Flutter 3.44.6 → 3.44.9 in CI.

**The AI tools give their memory back (#66).** Input ANR on a 2 GB Infinix
Smart 7 HD with the main thread idle in `nativePollOnce`. ORT's CPU arena kept
every run's high-water mark for the life of the process: two fills held
1.1 GB. With the arena off they hold 44 MB, run no slower, and the process
peak falls from 1.6 GB to 1.0 GB. Gallery saves also moved off the main thread
(150 ms for a 1.9 MB PNG on the emulator).

**The Home banner stops rendering behind the editor (#67).** Input ANR in
`J.N.VJJJ`, which is WebView's per-frame VSync callback waiting on the ad's
renderer with no timeout. Home stays mounted under pushed routes, so the
banner's `AdView` stayed attached and visible under the editor, where the AI
tools keep every core busy. `OnScreenOnly` now detaches it while Home is
covered and re-attaches the same ad on the way back.

If #66 survives, #68 is the next step: the PatchMatch fill instead of MI-GAN on
low-RAM phones. #67 cannot go to zero while ads are shown - the banner on Home
and the rewarded ad still render on our main thread.
