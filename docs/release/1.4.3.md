# Chromis 1.4.3 (build 11)

Previous release: 1.4.2+10. A **hotfix**: in 1.4.2, Remove object's AI did
not work on most phones. Bumped in `pubspec.yaml` and `AboutInfo.appVersion`;
built on Flutter 3.44.9.

## What broke

Tapping an object in Remove object said "Object removal AI isn't available on
this device" (Polish: "AI do usuwania obiektów nie jest dostępne…"). Found on
a Xiaomi 15 Ultra (Snapdragon 8 Elite, Android 16) running 1.4.2 from Play.

The MobileSAM encoder would not create its session:

    ORT_NOT_IMPLEMENTED: Failed to find kernel for com.microsoft.Gelu(1) ...
    implemented only for (tensor(float)), but the node in the model has
    (tensor(float16))

MobileSAM is fp16, and its GELUs are written out as `Erf` arithmetic - the
model file has no `Gelu` node at all. ORT 1.28 (`flutter_onnxruntime` 1.9.0,
new since 1.3.0, which shipped ORT 1.23) fuses that arithmetic into an fp16
`com.microsoft.Gelu` on any ARM CPU with fp16 arithmetic, then has no fp16
kernel for the node it made. That is nearly every phone sold since 2018, so
the AI tier of Remove object was dead for most users of 1.4.2; Erase brush and
the plain tap-to-remove of a cut-out's islands kept working.

Nothing caught it because every device test ran on the x86_64 emulator, which
has no fp16 path: there the fusion never fires and MobileSAM ran fine.

## The fix

`ortSessionOptions()` now also sets
`optimization.disable_specified_optimizers` to `GeluFusionL1;GeluFusionL2`,
so ORT runs the `Erf` steps unfused, as 1.23 did. The list is split on `;` -
the first attempt used a comma, which ORT reads as one unknown optimizer name
and silently ignores; `ort_session_options_test.dart` now pins both the names
and the separator.

U²-Net and MI-GAN are fp32 with zero and one `Erf`, so they lose nothing
measurable, and were very likely unaffected in 1.4.2.

## How it was verified

On the Xiaomi 15 Ultra, as a separate debug app (`applicationIdSuffix
".devtest"`, reverted) next to the Play install, so its projects were not
touched:

| Test | Before | After |
|---|---|---|
| `ort_engines_device_test` - MobileSAM | session fails, `ORT_NOT_IMPLEMENTED` | 2.7 s, mask 44,981 px of a 45,239 px disc |
| `ort_engines_device_test` - U²-Net | 654 ms, passes | 637 ms, passes |
| `inpaint_device_test` - MI-GAN | not run | 2.9 s, 0 object pixels left, resident 555 -> 533 MB |

The same file passes on the API 37 emulator with the fix (MobileSAM 8.9 s).
`flutter analyze` clean, `flutter test` green.
